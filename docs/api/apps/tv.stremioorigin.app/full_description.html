Stremio Origin: a native app for Stremio addons on LG webOS TVs (ARM), in English or Arabic.

Bring your own Stremio account and addons: the app ships empty and plays only the links your addons return.

  • Everything in Arabic: Home, the spotlight, Discover, Similar, the Library and the screensaver: names, posters, logos and descriptions in Arabic or English, from TMDB.
  • Search in Arabic: Type a name in Arabic or English: suggestions and results come in your language.
  • Picks that fit: Watch something similar shows TMDB's recommendations for that very title.
  • Fixes install themselves: Small updates install quietly while the TV is left alone, so you always have the latest fixes.

Unofficial: not affiliated with Stremio. Updates install from inside the app (Settings › About).
